Airdrop Finder reads a sealed snapshot of 758 DeFi protocols, ranks every pre-token one by an implied token value derived from its TVL, seven-day growth and tokenless age, and writes a dashboard that answers one question: which protocol is worth farming next, and what exactly do you do about it. Every row carries its own factor breakdown and a six-step farm plan with real costs and hold times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
